## Memory Rules

1. **Only store what changes behavior.** If a fact doesn't change how you'd respond, it's not worth storing.
2. **Be specific.** "User is busy" is useless. "User has 2hrs/day for business development, mornings only" is useful.
3. **Tag everything.** Tags enable fast retrieval when context matters.
4. **Confidence matters.** Don't treat inferences like confirmed facts.
5. **Prune ruthlessly.** If something is no longer relevant, delete it. Memory isn't a journal.
